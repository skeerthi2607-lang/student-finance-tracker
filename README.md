# 🚀 CampusCash – AI-Powered Student Budgeting App

CampusCash is a lightweight, intelligent web app built to help students take control of their personal finances, manage daily expenses, track wishlists, and get instant financial guidance using AI.

## ✨ Features
* 🔒 **Secure Auth**: User registration, login, and password management.
* 💸 **Income & Expense Tracking**: Categorize daily spending and monitor cash flow.
* 🎯 **Smart Budget Goals**: Set spending caps with real-time visual progress.
* 🤖 **AI Financial Coach**: Integrated OpenAI chat helper built for student money advice.
* 📊 **Visual Analytics**: Interactive charts powered by Chart.js.

## 🛠️ Tech Stack
* **Backend**: Python (Flask, SQLAlchemy)
* **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js
* **Database**: MySQL
* **AI Integration**: OpenAI GPT API
